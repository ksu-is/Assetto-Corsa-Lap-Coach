# Assetto-Corsa-Lap-Coach

A Python app that reads live telemetry from Assetto Corsa, saves every lap, and compares it to your best lap. It shows exactly which corners you're losing time in and gives simple tips like "brake later" or "get on the throttle sooner."

## Features (planned)
- Read live telemetry (speed, throttle, brake, gear, position) from AC shared memory
- Automatically save every lap to a file
- Compare any lap to your personal best
- Find the corners where you lose the most time
- Give plain-English driving tips per corner

## Requirements
- Windows (AC shared memory is Windows-only)
- Assetto Corsa (Steam)
- Python 3.x
